## 1. 概述

**v2.4.7** 为 **Patch Sage Attention DM** 节点新增 **`spargeattn`** 模式，由 **SpargeAttn-hswq**（`spas_sage_hswq_attn` v1.0.0，Owner 的 [SpargeAttn](https://github.com/thu-ml/SpargeAttn) fork，与官方 `sageattention` 包共存）驱动。

SpargeAttn 在 SageAttention2++ 量化内核之上叠加**两阶段块稀疏过滤**：

1. **阶段一（预测）：** Q/K 分块后进行均值池化与自相似度度量，通过压缩注意力图按 `topk` 比例选出每个 Q 块相关的 KV 块。
2. **阶段二（内核内跳过）：** 对存活的 KV 块，逐块 PV 阈值决定是否执行昂贵的 PV 计算——被跳过的块只付出廉价的 INT8 QK MMA 代价。

这正是论文内核基准（Figure 2）中最快的 **"SpargeAttn+Sage2"** 组合。

## 2. SpargeAttn 是什么

[SpargeAttn](https://arxiv.org/abs/2502.18137)（ICML 2025）是通用、免训练的稀疏注意力方法。**-hswq fork** 在其上新增：逐块 INT8 scale sweep（E2-a，`SPARGE_SCALE_SWEEP=1` 门控）、阈值余量校准（E2-b）、层重要性加权（E2-d）——**不改变量化位宽**（QK 保持 INT8，PV 保持 FP8），内核零改动。

## 3. 实现细节

### 3.1 新增 `spargeattn` 模式与 `sparge_topk` 输入

- `sage_attention` 下拉框新增 `spargeattn`（追加在末尾——旧工作流的控件映射不受影响）。
- 新增可选 **`sparge_topk`** 输入：KV 块保留比例，**COMBO 下拉框**，固定选项 `0.05` … `1.0`（步长 0.05，默认 `0.5`）。特意采用下拉框，使 UI 无法保存 `0` 这类非法值（内核按 `selected = topk * K` 计算，0 会选出零个块）。`1.0` = 计算全部块（不跳过）。
- 其他模式忽略此参数。

### 3.2 独立代码路径（完全分离）

- 新增专用 `get_sparge_func_dm()` —— 与现有 SageAttention 各模式完全分离。SageAttention 包装器构建部分抽取为 `_build_sage_attention_tail()`，行为不变（既有 5 种模式回归验证通过）。
- 调用 fork 推荐的即插即用 API `spas_sage2_attn_meansim_topk_cuda`（INT8 QK + FP8 PV，SageAttention2++ 块稀疏内核）。
- 独立的版本检测（`get_sparge_attn_info()`）；与官方 `sageattention` 包互不影响。

### 3.3 约束回退

显式契约检查不满足时回退到 PyTorch SDPA **并输出日志**（绝不静默）：

| 条件 | 原因 |
|---|---|
| 带注意力掩码 | SpargeAttn 签名接受 `attn_mask` 但内核不使用——直接透传会静默丢弃掩码 |
| headdim 不是 64/128 | 内核断言（如 SD1.5 的 headdim 160） |
| seq_len < 128 | 内核断言 |
| 包未安装 | 每种唯一消息只提示一次 |

### 3.4 控件顺序兼容与数值净化

- `sparge_topk` 声明在 `allow_compile` **之后**，v2.4.7 之前保存的工作流按原控件值加载。
- 运行时净化：`None` / `0.0` / 负值 / `NaN` / 非数值 / `>1.0` 一律映射到默认 `0.5`；`(0, 1]` 内的值原样使用。每次替换都输出日志。

## 4. 安装（Windows 预构建 wheel）

`sageattention`（SA2）、`sageattn3`（SA3）、`spas_sage_hswq_attn`（SpargeAttn-hswq）的 Windows 预构建 wheel 已发布在 Hugging Face：

**[https://huggingface.co/ussoewwin/Sage-Attention-and-Sparge-Attention-HSWQ](https://huggingface.co/ussoewwin/Sage-Attention-and-Sparge-Attention-HSWQ)**

选择与环境匹配的 wheel（`cp3xx` = Python 版本，`torch2.xx` / `cu1xx` = torch/CUDA 构建）。Python 3.13 / torch 2.14 / CUDA 13.2 示例：

```bash
pip install spas_sage_hswq_attn-1.0.0+cu132torch2.14.0cxx11abitrue-cp313-cp313-win_amd64.whl
```

## 5. 验证

- GPU 内核调用在 RTX 5060 Ti（SM120，torch 2.14.1+cu132，Python 3.13）实测通过：`spas_sage2_attn_meansim_topk_cuda` 成功。
- 约束回退实测：headdim 160 → SDPA、seq_len 64 → SDPA、`topk` 0.0/None/NaN/'garbage' → 净化为 0.5。
- 回归：既有 5 种 SageAttention 模式构建与运行不变。
- Live 部署：已同步到 `custom_nodes/ComfyUI-DistorchMemoryManager/`，并在真实 SDXL 生成中验证（SpargeAttn 生效、16/16 步完走）。

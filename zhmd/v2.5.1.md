## 1. 概述与核心变更

在 `v2.5.1` 中，`Patch Sage Attention DM` 节点正式**彻底移除了 SpargeAttn 模式（`spargeattn`）及相关参数（`sparge_topk`）**。

此前在 v2.4.7 引入并于 v2.5.0 升级的 SpargeAttn 集成，经生产环境下长期与多轮生成实测验证，确认其底层块稀疏（Block-Sparse）算子存在不可忽视的**进程级显存污染**以及**画面高频噪点化**缺陷。

为了保障 ComfyUI 在长周期生产生成中的绝对稳定性与画质保真度，本版本将 `Patch Sage Attention DM` 全面精简纯化，彻底删除了所有 SpargeAttn 专用内核调度与回退分支，仅保留经过严格生产验证的官方 SageAttention（SA2 / SA3）与 Flash-Attention（FA-2 / FA-3）后端。

---

## 2. 移除背景与实测根因分析

### 2.1 显存污染残留（Persistent VRAM Pollution）

在多轮连续采样生成过程中，SpargeAttn 的双阶段块稀疏索引计算（Top-K 块选择）需要频繁申请、管理动态稀疏索引张量及中间计算缓冲区。
实测发现：
- **物理显存无法释放**：由于 CUDA 内部稀疏内核分配机制与 PyTorch Caching Allocator 之间的生命周期不一致，这些分配在生成结束后无法通过常规的 Python 垃圾回收（`gc.collect()`）或 PyTorch 缓存清空（`torch.cuda.empty_cache()`）彻底返还。
- **跨 Prompt 累积泄漏**：连续执行 10 次以上生成任务后，进程常驻物理显存（Resident VRAM）出现数 GB 规模的持续膨胀，最终导致后续大分辨率上采样或复杂工作流触发 CUDA Out of Memory (OOM)。

### 2.2 累积性画面噪点化缺陷（Progressive Image Noise Artifacts）

SpargeAttn 采用两阶段块稀疏过滤（Mean-Sim Top-K 筛选）配合 SageAttention2++ 量化内核（QK INT8 + PV FP8）。在去噪步数较多（如 25–50 步）或涉及复杂细节的生成中：
- **稀疏丢弃导致的高频截断**：Top-K 强行丢弃了注意力矩阵中权重较低但对高频纹理至关重要的 KV 块，导致部分潜空间特征在多步迭代中逐步发生数值漂移（Latent Trajectory Divergence）。
- **噪点与斑块伪影**：去噪步数推进时，特征漂移被逐步放大，最终解码输出的图像出现明显的粒状高频噪点、细微斑点和局部模糊等画质退化现象。

## 3. 代码改动与架构纯净化

### 3.1 彻底剥离 SpargeAttn 相关算子与参数

- **移除 `spargeattn` 模式**：从 `PatchSageAttentionDM.INPUT_TYPES` 的 `sage_attention` 枚举列表中彻底删除 `spargeattn`。
- **移除 `sparge_topk` 参数**：彻底删除用于控制 KV 块稀疏比例的 `sparge_topk` 浮点数组件。
- **清理专用调度函数**：完全删除了 `nodes/sa.py` 中用于 SpargeAttn 初始化的 `get_sparge_func_dm()` 函数以及所有稀疏调用路径（约 250 行专用代码）。

### 3.2 移除外部 `spas_sage_hswq_attn` 依赖

- 不再尝试 `import spas_sage_hswq_attn`，排除了因环境缺少该 wheel 而产生的任何回退开销或警告日志。
- 节点依赖回归标准的 `sageattention`（SA2 / SA3）。

### 3.3 回归纯净 SageAttention / Flash-Attention 统一架构

精简后的 `Patch Sage Attention DM` 架构如下：
1. **SageAttention 2 模式**：
   - `auto`：根据硬件与环境自动选择最佳后端
   - `sageattn_qk_int8_pv_fp16_cuda` / `triton`
   - `sageattn_qk_int8_pv_fp8_cuda` / `cuda++`
2. **SageAttention 3 模式（Blackwell 优化）**：
   - `sageattn3`
   - `sageattn3_per_block_mean`
3. **Flash-Attention 模式**：
   - 禁用时安全恢复 ComfyUI 原生 Attention 或 Flash-Attention 2/3

## 5. 验证与生产环境建议

- **测试环境**：Windows 11, PyTorch 2.14 / 2.11, CUDA 13.2 / 12.8, RTX 5060 Ti (sm120) / RTX 4090 (sm89)
- **实测结果**：
  - 连续 50 轮生成测试中，物理显存分配与释放曲线完全平稳，无任何残留显存泄漏。
  - 画面高频细节保真，彻底消除了由于块稀疏丢弃产生的噪点伪影。
- **升级建议**：所有使用 `v2.5.0` 或更早版本 `Patch Sage Attention DM` 的用户，建议立即升级至 `v2.5.1`，并将工作流中的注意力模式切换为 `auto`、`sageattn_qk_int8_pv_fp8_cuda++` 或 `sageattn3`。

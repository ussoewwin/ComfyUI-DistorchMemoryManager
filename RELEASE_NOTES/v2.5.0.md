## Overview: Patch Sage Attention DM — SpargeAttn-hswq API Alignment & Zero-Copy Architecture

This release aligns the `spargeattn` mode in **Patch Sage Attention DM** (`nodes/sa.py`) with the current API of the **SpargeAttn-hswq** fork (fork >= 1.1), mirroring the integration standard implemented in `ComfyUI-SeedVR2-VideoUpscaler-with-TensorRT`. It introduces zero-copy NHD execution, model softmax scale contract forwarding, ComfyUI 0.38.x `low_precision_attention` opt-out support, and fixes a latent internal SDPA fallback tensor layout defect.

---

## Key Improvements

### 1. Zero-Copy NHD Entry Point (`spas_sage2_attn_meansim_topk_nhd_cuda`)
- **Background**: Standard ComfyUI passes attention inputs in NHD layout (`[batch, seq, heads, dim]`, `skip_reshape=False`). Previously, each attention execution performed 3 consecutive transpose copies (`.transpose(1, 2).contiguous()`) to HND format (`[batch, heads, seq, dim]`) and transposed the output back, incurring measurable CUDA memory bandwidth overhead and kernel launch latency.
- **Solution**: On SpargeAttn-hswq fork >= 1.1, inputs with `skip_reshape=False` directly invoke the new `spas_sage2_attn_meansim_topk_nhd_cuda` entry point. Tensor transposes are completely bypassed for zero-copy execution. Inputs with `skip_reshape=True` and older forks safely retain the HND entry `spas_sage2_attn_meansim_topk_cuda`.

### 2. Softmax Scale Contract Forwarding (`kwargs["scale"]`)
- Implements the ComfyUI 0.38.x contract where model architectures can provide an explicit `kwargs["scale"]` factor.
- Previously, `kwargs["scale"]` was silently discarded and the kernel-internal default `1.0 / sqrt(head_dim)` was used. Now, model-supplied `scale` is explicitly forwarded to both the SpargeAttn kernel (`sm_scale`) and the PyTorch SDPA fallback paths.

### 3. ComfyUI 0.38.x `low_precision_attention=False` Opt-Out Gate
- Added routing for the standard `low_precision_attention` toggle: when `kwargs.get("low_precision_attention", True) is False`, execution immediately branches to native `comfy.ldm.modules.attention.attention_pytorch`, perfectly matching the behavior of native `attention_sage`.

### 4. Tensor Layout Fix in Internal SDPA Fallback
- Fixed a latent v2.4.7 issue where constraint fallbacks (such as attention mask presence, seq_len < 128, or unsupported head dimensions) passed NHD tensors directly into `attention_pytorch` without declaring `skip_reshape=skip_reshape`. This triggered tensor assertion exceptions and forced a secondary recovery via the outer `except` block. Fallbacks now cleanly dispatch with exact parameter propagation.

### 5. Patch-Time Entry Resolution & Graceful Fallback
- Resolved kernel function pointers once at patch time inside `get_sparge_func_dm()` rather than on every attention forward call.
- If a fork lacks the expected entry points, it logs an informative warning and safely falls back to PyTorch SDPA instead of terminating with an unhandled `AttributeError`.
